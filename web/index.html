Design notes

    About this project

    AeroFrame X1 is a design study, not a product. Every part on it was modelled parametrically in Python using the OpenCASCADE geometry kernel; every mass, stress and safety factor on these pages was computed from that same geometry rather than typed in. Changing one number in the parameter file regenerates the model, the bill of materials, the drawings and the analysis together.

    What it is meant to show

    • Designing mechanisms and electromechanical assemblies as a system, not as separate parts.
    • Choosing a manufacturing process per part, and then respecting that process's design rules.
    • Sizing parts with hand calculations first and confirming them with finite element analysis.
    • Producing the drawings and neutral CAD a supplier would actually need.

    Honest limitations

    • The finite element work is linear-static on first-order tetrahedra. It is a comparison and screening tool here, not a certification analysis.
    • Bolted joints are modelled as fixed restraints. No contact, preload or friction is simulated.
    • Composite parts are treated as isotropic, which is reasonable for the tube in axial bending and wrong elsewhere.
    • Endurance is a first-order estimate from battery energy and is good to perhaps 20 %.
    • No part of this design has been built or flown.
